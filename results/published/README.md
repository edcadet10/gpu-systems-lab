# Published measurements

No hardware measurement has been accepted yet.

A future result set belongs in a dedicated subdirectory containing its suite
`manifest.json` and every referenced raw child report. It must be produced from a
clean commit, pass the recursive validator, satisfy the pre-registered comparison
rule, include profiler evidence for its mechanism, and state the exact hardware and
software boundary.

This empty registry is deliberate: simulated or CPU-only observations are not
substituted for target-GPU latency, code-generation, profiler, or collective evidence.
